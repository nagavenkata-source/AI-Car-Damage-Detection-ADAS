# 🚗 AI-Driven Car Damage Detection + ADAS System

## 📄 Overview
This project combines real-time car-damage detection and Advanced Driver-Assistance System (ADAS) capabilities.  
It uses **YOLOv8**, **AWS Rekognition**, and **DeepSORT** to identify, classify, and track vehicle damages, generating automatic reports for insurance assessment and safety analytics.

---

## 🧠 Tech Stack
- **Languages:** Python  
- **Libraries:** YOLOv8 (ultralytics), OpenCV, TensorFlow, DeepSORT, boto3  
- **Cloud:** AWS Rekognition, AWS S3  
- **Tools:** Jupyter Notebook / VS Code / GitHub / Proxmox  
- **Environment:** macOS / Linux / Windows
